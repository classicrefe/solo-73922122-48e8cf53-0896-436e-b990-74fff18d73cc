# 水位时长核算系统

水文年报场景：调查范围确定前无法固定警戒水位，因此本系统**导入时只保存逐日摘要**，
警戒水位在查询时以任意整数毫米临时给出，查询全程只读摘要、不改数据。

## 核算规则

1. 导入单站、按时间有序的 CSV：UTC 整秒时间戳（`...Z` 或 `+00:00`），水位为
   有符号 64 位整数毫米（`-9223372036854775808 … 9223372036854775807`）。
2. 相邻观测间隔 **≤ 1 小时**：段内按直线（线性）估算水位；**> 1 小时**：整段判未测，不插值。
3. 跨午夜的观测段按两个 UTC 日的实际占秒分摊，仍沿用**同一条直线**；
   统计口径为 UTC 自然日，每天固定 86400 秒。
4. 数据库只保存逐日摘要，原始观测不落库，也不按整数毫米逐档展开。
5. 同一站任一天与已有摘要重叠或写入失败即**整批退回**（单事务回滚），原摘要保持不变。
6. 查询选择日期范围并填写任意整数毫米警戒线，输出：
   - 达到或超过警戒线的累计秒数（**恰好等于警戒线的平水段算达标**）；
   - 区间内有测秒数、未测秒数，并附逐日明细；
   - 无任何摘要的日期按全天未测列示。
7. 改变警戒线只是新的只读查询，不会重新导入或修改摘要。

## 摘要如何支持任意警戒线（设计要点）

每张摘要表按“站 × UTC 日”只保存一行 `daily_summary`，其中 `profile` 列保存当日
**日内线性片段**的 JSON：`[[秒数, 段起点水位, 段终点水位], ...]`，水位用精确有理数
（`分子/分母` 文本）。导入后只保存日摘要，绝不按毫米逐档展开。

```json
{"version":2,"pieces":[[1800,"100/1","120/1"],[3600,"120/1","50/1"]]}
```

查询警戒线 `h` 时，对每个片段直接求水位 `≥ h` 的精确秒数并累加：

- 平水片段：`h ≤ 平水水位`整段计入（恰好等于也算）；
- 线性片段：`h ≤ 低端`整段计入，`低端 < h ≤ 高端`按 `(hi-h)/(hi-lo)` 比例；
- `h > 高端`计 0。

水位插值和秒数累计全程使用 `fractions.Fraction`，因此 `2**63-1` 与 `2**63-2`
这类只差 1 毫米的大整数读数仍会正确算成斜坡，不会被浮点误判为平水；
警戒线本身也可超出 SQLite 整数范围（按日内最低/最高水位直接判定，不绑定参数）。

逐日与合计秒数都先对**精确有理数**按 3 位小数四舍五入再展示，避免浮点累计误差。

旧库兼容：升级前写入的逐毫米尾分布表 `daily_level_tail` 保留只读兼容；
`profile` 为空的旧摘要继续按原有 `min/max + tail(h)` 口径与已存精度参与核算，
新旧摘要可在同一区间查询中一起合计。`init_db` 会为旧库自动补上 `profile` 列。

## 目录结构

```
app/            Flask 应用（db / exact / importer / query / web + templates）
tests/          pytest 用例（32 项：解析校验、线性/平水/跨午夜/未测、大整数全范围、
                警戒线越界、重叠与写入失败整批退回、旧摘要兼容、舍入口径、网页端到端）
scripts/        示例 CSV 生成脚本
samples/        演示 CSV（由脚本生成）
Dockerfile, docker-compose.yml, docker/entrypoint.sh
wsgi.py         gunicorn 入口
```

## Docker Compose 启动

```bash
docker compose up --build
# 浏览器打开 http://localhost:8000
```

SQLite 数据库位于命名卷 `waterlevel-data` 内的 `/data/waterlevel.db`，容器重建不丢数据。

## 本地（无 Docker）运行

```bash
pip install -r requirements.txt
python scripts/generate_samples.py          # 生成 samples/s001_waterlevel.csv
flask --app wsgi:app init-db                # 可选，首次访问也会自动建表
flask --app wsgi:app run --port 8000
```

## 网页演示流程

1. 打开“导入观测 CSV”，站码填 `S001`，选择 `samples/s001_waterlevel.csv` 导入。
   示例含跨午夜线性段、平水段（120mm）、5400 秒未测缺口、上升段和下降段。
2. 再次提交同一文件，页面提示“与已有摘要重叠……整批退回”，摘要不增加。
3. 打开“警戒线核算查询”，站码 `S001`、日期 `2026-01-01` 至 `2026-01-02`：
   - 警戒线 120mm → 达标 1,800 秒（平水段；端点瞬时值不计时长）；
   - 警戒线 110mm → 达标 2,700 秒（900 秒跨午夜段 + 1,800 秒平水段）。
4. 把日期延到 `2026-01-03`，无数据那天按 86,400 秒未测列示。
5. 警戒线可填超出 64 位范围的整数（如 `9223372036854775808`），页面按 0 秒给出而不报错。

## CSV 格式

```csv
timestamp_utc,level_mm
2026-01-01T23:30:00Z,100
2026-01-02T00:00:00Z,120
2026-01-02T00:30:00Z,9223372036854775807
```

表头可选；空行跳过；时间戳必须严格递增；拒绝小数秒、非 UTC 时区、非整数水位，
以及超出有符号 64 位整数范围的水位读数。
